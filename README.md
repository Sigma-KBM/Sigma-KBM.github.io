# KMB Data Bridge website

Static bilingual consulting portfolio prepared for GitHub Pages.

## Local preview

Open `index.html` in a browser. No build step is required.

## Contact workflow

The requirements form creates a structured, pre-addressed email to `manue@sigma-emprende.com`. This intentionally keeps the first exchange in writing. Before public launch, replace this with a form provider or automation only if automatic acknowledgements and case references are required.

## Publish with GitHub Pages

1. Create a new public GitHub repository named `Sigma-KBM.github.io` for a user site, or a project repository such as `kmb-data-bridge`.
2. Add the contents of this folder to that repository.
3. In GitHub, open **Settings → Pages** and deploy from the default branch.
4. If using a custom domain later, add it in **Settings → Pages** before changing DNS records with the domain registrar.
